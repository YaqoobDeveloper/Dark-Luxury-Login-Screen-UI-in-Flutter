# Dark Luxury Login Screen UI in Flutter 🌑✨

A modern and elegant **dark luxury login screen UI** built with Flutter.

This project focuses on creating a premium authentication experience with a dark aesthetic, clean typography, polished UI elements, reusable widgets, and a responsive layout.

## ✨ Features

- 🌑 Modern dark luxury login UI
- ✨ Premium and elegant visual design
- 🔐 Email and password login fields
- 👁️ Password visibility option
- 👤 Remember me option
- 🔵 Social sign-in buttons
- 🧩 Reusable Flutter widgets
- 📱 Responsive layout
- ⚡ Lightweight and fast UI
- 🎯 Clean and organized project structure

## 🛠️ Built With

- **Flutter 3.47.2**
- **Dart**

## 📋 Requirements

- Flutter **3.47.2** or compatible version
- Dart SDK included with Flutter
- Android Studio or VS Code
- Xcode for iOS development

## ▶️ Run

### 1. Clone the repository

```bash
git clone https://github.com/YaqoobDeveloper/Dark-Luxury-Login-Screen-UI-in-Flutter.git
```

### 2. Navigate to the project

```bash
cd Dark-Luxury-Login-Screen-UI-in-Flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
